## Config

```ts
import { defineConfig } from 'unocss'
import { presetWind4 } from '@unocss/preset-wind4'
import presetUnocss from '@starweave-lab/unocss-preset'

export default defineConfig({
  presets: [presetWind4(), presetUnocss()],
  theme: {
    colors: {
      primary: '#3b82f6',
    },
  },
})
```

## What is used

| Class                   | Source                                   |
| ----------------------- | ---------------------------------------- |
| `flex-between`          | Layout shortcut                          |
| `grid-equal-cols`       | Layout shortcut                          |
| `b-t-2-primary`         | Border rule                              |
| `b-b-dashed-red`        | Border rule (style + color)              |
| `text-2md` / `text-xs`  | Text-size rules (override `presetWind4`) |
| `effect-interactive`    | Interaction feedback shortcut            |
| `max-w-xl` / `bg-white` | Provided by `presetWind4`                |

::: tip
`primary` / `green` come from the UnoCSS theme. Define them in `theme.colors`
before use.
:::
